# התקציב של משפחת מור

אפליקציה לתכנון ומעקב של ההוצאות החודשיות. מגדירים פעם אחת את ההכנסות וההוצאות הקבועות, מעדכנים את כרטיסי האשראי במהלך החודש, והאפליקציה מראה כמה צפוי להישאר בסוף החודש, או כמה יחסר.

**האפליקציה:** https://mor-family-budget.netlify.app

## איך משתמשים

- **בטלפון:** בפתיחה מהדפדפן מופיע כרטיס "שמירת Mor בטלפון" שמוסיף את האפליקציה למסך הבית, עם האייקון והשם Mor. כשפותחים מהאייקון הכרטיס לא מופיע.
- **כניסה:** אימייל וסיסמה. אפשר להפעיל כניסה עם טביעת אצבע או זיהוי פנים, ואז האפליקציה תבקש אותם בכל פתיחה.
- **בני משפחה:** מי שמנהל את האפליקציה מוסיף אימייל בלשונית "הגדרות" ומקבל קוד הצטרפות בן 6 ספרות. הקוד תקף לשבוע. מי שקיבל אותו בוחר בכניסה "קיבלתי קוד הצטרפות". מי ששכח סיסמה מקבל קוד חדש באותה דרך.
- **התראות:** כל 3 ימים ב-19:00 נשלחת לטלפון התראה עם מצב החודש. מפעילים אותן בלשונית "הגדרות" בכל מכשיר. באייפון צריך קודם להוסיף את האפליקציה למסך הבית ולפתוח אותה משם.
- **מחזור החיוב:** חיובי האשראי מתאפסים ב-13 לחודש. מה שמוציאים מה-13 והלאה נספר בחודש הבא. אפשר לשנות את היום בלשונית "תכנון".

## איך זה בנוי

- האתר יושב ב-Netlify. הדף נמצא בתיקייה `public`, והשרת בתיקיות `lib` ו-`netlify/functions`.
- הנתונים נשמרים באחסון של האתר ב-Netlify, לא בריפו הזה. אין כאן סכומים אמיתיים.

## להמשיך לפתח

פותחים סשן של Claude Code על הריפו ומבקשים את השינוי במילים. ההוראות ל-Claude נמצאות ב-`CLAUDE.md`. Claude יעדכן את הקוד, יריץ את הבדיקות ויעלה את הגרסה החדשה לאותה כתובת, והנתונים נשארים במקומם.
