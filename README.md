# התקציב של משפחת מור

אפליקציה לתכנון ומעקב של ההוצאות החודשיות. מגדירים פעם אחת את ההכנסות וההוצאות הקבועות, מעדכנים את כרטיסי האשראי במהלך החודש, והאפליקציה מראה כמה צפוי להישאר בסוף החודש, או כמה יחסר.

**האפליקציה:** https://claude.ai/artifact/J5n31DXJya4L8eGoQwXekA

## איך זה בנוי

- כל האפליקציה נמצאת בקובץ אחד, `index.html`.
- הנתונים (התכנון, עדכוני האשראי והתשלומים הנוספים) נשמרים בחשבון Claude, בתוך האפליקציה, ולא בריפו הזה. אין כאן סכומים אמיתיים.
- חיובי האשראי מתאפסים ב-13 לחודש: מה שמוציאים מה-13 והלאה נספר בחודש הבא. אפשר לשנות את היום בלשונית "תכנון".

## להמשיך לפתח

פותחים סשן של Claude Code על הריפו ומבקשים את השינוי במילים. ההוראות ל-Claude נמצאות ב-`CLAUDE.md`: הוא יעדכן את `index.html`, יריץ את הבדיקות ויפרסם לאותו קישור, כך שהנתונים נשארים במקומם.

## בדיקות

pip install -r requirements-dev.txt
